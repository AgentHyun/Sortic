# # Sortic 🛒

도소매 상인들의 영수증 생성과 재고 관리를 자동화하는 웹 애플리케이션입니다.

## 📅 개발 기간

2025년 4월 20일 ~ 2025년 6월 11일

## 👨‍💻 개발 인원

- 총 3명

## 🛠️ 사용 기술

- **Frontend**: React, JavaScript, CSS, HTML
- **Backend**: Spring Boot, MyBatis
- **Database**: MySQL
- **State Management**: Jotai
- **Drag & Drop**: Dnd-kit

## 🔗 GitHub

- [Sortic GitHub Repository](#)

## 💡 주요 기능 및 역할

- `SpringBoot`의 `MyBatis`를 활용하여 `MySQL`과 연동, `MVC 패턴` 기반의 CRUD 비동기 함수 구현
- 사용자 편의성을 고려한 **UX 개선**
- `React`의 `Dnd-kit`을 사용하여 **섹션 간 Drag & Drop** 기능 구현

## 📌 프로젝트 요약

Sortic은 도소매 업자들이 매일 반복하는 **영수증 작성**, **상품 재고 확인**, **판매 흐름 파악** 등의 과정을 자동화하여 업무 효율을 높이고자 개발된 웹 애플리케이션입니다.
